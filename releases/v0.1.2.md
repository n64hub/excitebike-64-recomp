A fix for Excitebike 64: Recompiled, for Windows and Linux. You still need your own ROM of the USA release, Rev 1 (the [v0.1.0 notes](https://github.com/n64hub/excitebike-64-recomp/releases/tag/v0.1.0) have the rest: what works and how to run it).

**Windows:** unzip `Excitebike64Recompiled-v0.1.2-windows-x64.zip` and run `Excitebike64Recompiled.exe` from that folder. **Linux (x86-64):** extract `Excitebike64Recompiled-v0.1.2-linux-x64.tar.gz` and run `Excitebike64Recompiled` in that folder. A ROM stored by an earlier release is kept, and so are the season and the settings.

- A Controller Pak in controller 1's port, kept in the saves folder as `controllerpak_1.mpk`: the boot no longer warns that no Controller Pak was found, and Time Trials save their ghosts there and load them back after a restart. Controller 1's Rumble Pak keeps working beside it

Not checked yet: copying a custom track to the Controller Pak and racing it. Reports are welcome on the [issues page](https://github.com/n64hub/excitebike-64-recomp/issues).
