Excitebike 64: Recompiled v0.1.1 for Windows and Linux. You still need your own ROM of the USA release, Rev 1 (a big-endian `.z64`, 16 MiB, SHA-1 `c2fac422af135409c1b38569b309f9d452c81c35`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `Excitebike64Recompiled-v0.1.1-windows-x64.zip` and run `Excitebike64Recompiled.exe` from that folder. **Linux (x86-64):** extract `Excitebike64Recompiled-v0.1.1-linux-x64.tar.gz` and run `Excitebike64Recompiled` in that folder.

**What's new:**

- A Controller Pak in controller 1's port, kept in the saves folder as `controllerpak_1.mpk`: the boot no longer warns that no Controller Pak was found, and Time Trials save their ghosts there and load them back after a restart. Controller 1's Rumble Pak keeps working beside it.
- Widescreen: the bikes' dust, mud, splashes and exhaust puffs are drawn out to the window's edges, where they used to vanish at the old 4:3 frame's sides.

**Not checked yet:** copying a custom track to the Controller Pak and racing it, and play sessions longer than a few minutes. Reports are welcome on the [issues page](https://github.com/n64hub/excitebike-64-recomp/issues).

The same game plays in a browser at [n64hub.com/excitebike-64](https://n64hub.com/excitebike-64/).
