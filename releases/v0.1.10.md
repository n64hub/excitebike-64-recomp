Fixes for Excitebike 64: Recompiled, for Windows and Linux. You still need your own ROM of the USA release, Rev 1 (the [v0.1.0 notes](https://github.com/n64hub/excitebike-64-recomp/releases/tag/v0.1.0) have the rest: what works and how to run it).

**Windows:** unzip `Excitebike64Recompiled-v0.1.10-windows-x64.zip` and run `Excitebike64Recompiled.exe` from that folder. **Linux (x86-64):** extract `Excitebike64Recompiled-v0.1.10-linux-x64.tar.gz` and run `Excitebike64Recompiled` in that folder. A ROM stored by an earlier release is kept, and so are the season, the settings and the Controller Pak.

- Fixed light-blue seams that flickered across the track and up the canyon walls on Mountain Quarry, between track sections, in the frames drawn between the game's own (#24)
- Each frame, only the depth of the picture is copied back from the graphics card for the game to read (it looks there for the hills in front of the stadium lights), not the picture as well: the browser version draws about a third more frames a second at a large size (#23)
- In a window wider than 4:3, the other riders stay drawn out to the window's sides instead of vanishing past the 4:3 frame's edges, and so does the place marker over the rider one place ahead (#32)

Reports are welcome on the [issues page](https://github.com/n64hub/excitebike-64-recomp/issues).
