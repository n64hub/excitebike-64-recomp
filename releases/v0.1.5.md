A new option for Excitebike 64: Recompiled, for Windows and Linux. You still need your own ROM of the USA release, Rev 1 (the [v0.1.0 notes](https://github.com/n64hub/excitebike-64-recomp/releases/tag/v0.1.0) have the rest: what works and how to run it).

**Windows:** unzip `Excitebike64Recompiled-v0.1.5-windows-x64.zip` and run `Excitebike64Recompiled.exe` from that folder. **Linux (x86-64):** extract `Excitebike64Recompiled-v0.1.5-linux-x64.tar.gz` and run `Excitebike64Recompiled` in that folder. A ROM stored by an earlier release is kept, and so are the season, the settings and the Controller Pak.

- In a window wider than 4:3, the black fades between screens sweep across the whole window: the left side no longer stays lit as one flat strip beside the picture until the fade's very end (#4)
